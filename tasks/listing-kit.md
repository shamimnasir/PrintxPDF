# Listing kit

Copy to paste when submitting PrintxPDF anywhere. Kept here so every listing says the same thing,
and so the claims match what the site actually does.

## The honest position on directories

Most "submit your site to 500 directories" services are a link scheme. Google has devalued generic
web directories for over a decade and treats bulk submission as a spam signal, so the downside is
real and the upside is roughly zero. None of those are listed below.

What follows is places where a person might actually find the tool. Every one needs an account,
which means you submit them, not me. They are ordered by what they are likely to return.

## Worth the effort

| Where | Why | Effort |
| --- | --- | --- |
| **AlternativeTo** | People search "Smallpdf alternative" and "iLovePDF alternative" there. Directly the query you want to win. | 15 min |
| **Product Hunt** | One large spike and a durable backlink. Worth planning rather than firing off: pick a Tuesday or Wednesday, have the screenshots ready. | A morning |
| **Show HN** | Free, and the privacy angle (files never leave the tab) is exactly what that audience responds to. Post it plainly, no marketing voice. | 20 min |
| **SaaSHub** | Aggregator that ranks well for "X alternative" queries. | 15 min |
| **Reddit** r/pdf, r/software, r/InternetIsBeautiful | Real traffic if you post as a person solving a problem. Read each subreddit's self-promotion rule first; several will ban for a straight plug. | 30 min |
| **awesome-privacy** and similar GitHub lists | A pull request, not a form. The browser-only tools genuinely qualify. | 20 min |

## Probably not worth it

- **G2 and Capterra** are built around paid B2B software and buyer intent. A free browser tool
  rarely gets traction, and both will chase you to buy a listing.
- **AI tool directories** do not fit. Nothing here is an AI product, and saying otherwise to get
  listed would be the kind of claim the rest of the site avoids.
- **BetaList** is for pre-launch products. This one has shipped.

## The copy

**Name:** PrintxPDF

**One line (60 chars):**
Print only what matters. Fix any PDF.

**Short (150 chars):**
Turn any web page into a clean printout or PDF, then merge, sign, shrink or convert any PDF. Free, no account, and nearly all of it runs in your tab.

**Medium (300 chars):**
PrintxPDF strips the ads, menus and comment threads out of any web page so you can print or save
just the article. It also carries 46 PDF tools: merge, split, sign, compress, OCR, redact, convert
and more. Most run entirely in your browser, so the file never leaves your computer. No account, no
watermark.

**Long:**
PrintxPDF does two things. Paste a link and it keeps only the article, dropping the ads, navigation
and comment threads, so a recipe prints on one page instead of six. Drop in a PDF and you get 46
tools: merge, split, organise, compress, sign, add page numbers, OCR a scan into searchable text,
black out private details, convert to and from Word, Excel, PowerPoint, images and ebooks.

Nearly every tool runs inside the browser tab, so the document never leaves the computer, which
matters for contracts, bank statements and medical records. A handful of jobs need software a
browser does not have, including PowerPoint conversion, ebook conversion and PDF passwords. Those
run on a server, say so on the page before you start, and the file is deleted as soon as it is done.

The browser tools are free with no account, no card and no watermark, and they stay that way.
